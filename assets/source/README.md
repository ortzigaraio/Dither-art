# Source images for the landing page

These are the owner's paintings (Basque fishing and rural scenes). They were cropped to remove the signature, watermark and frame,
upscaled ×3 with Lanczos plus a light unsharp mask, auto-levelled, and exported to WebP (quality 86).

| File | What it is |
|---|---|
| `*.webp` | The full scene. |
| `*-recorte.webp` | The figures cut out with a transparent background (rembg, `isnet-general-use`), so the Dither effects don't waste detail on the background. |

**Rights:** confirm you have the right to publish derivatives of these paintings. Several look like works by 20th-century Basque painters,
which are probably not in the public domain.
